# Annoy Release Hub — Personal Working Copy

This repository is the personal release workspace of **knobbyintens** for the Orbit Labs
`Annoy` model release programme.

The canonical shared project mirror lives in the archive organisation and is
read-only for individual contributor accounts. Release branches are prepared in
this personal working copy and later synced into the shared mirror by the
automation team.

## Layout

- `releases/<version>/manifest.json` — release bundle manifest
- `releases/<version>/notes.md` — optional release notes

## Branch naming

Release branches use the form `release-<version>`, for example `release-2.3`.
